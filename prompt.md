PREMIUM CAFE WEBSITE PROMPT FRAMEWORK

1. Homepage Copy Prompt

Create premium homepage copy for a modern local cafe website. Generate a strong emotional headline, modern subheadline, short introduction, value proposition, and premium CTA buttons. The website should feel cozy, luxurious, visually aesthetic, and welcoming. Use human-sounding and emotionally engaging language while avoiding robotic AI phrasing or generic business copy. The final content should feel realistic and ready for a real-world website launch. Maintain a warm, stylish, friendly, and premium tone throughout the copy.

--------------------------------------------------

2. Services Page Prompt

Create premium service page content for a modern cafe website. Generate content for artisan coffee, desserts, breakfast meals, workspace seating, free WiFi, and live music or events. For each service, include a service title, premium short description, emotional customer benefit, and reasons why customers should choose the service. The language should feel business-specific, natural, customer-focused, and publish-ready while avoiding generic AI-generated wording.

--------------------------------------------------

3. CTA Section Prompt

Create persuasive CTA sections for a premium cafe website. Generate booking table CTAs, visit cafe CTAs, order now sections, and evening coffee promotional CTAs. The call-to-action copy should create urgency, excitement, emotional connection, and encourage user interaction. Use modern and premium language similar to luxury lifestyle brands. Example styles include “Reserve Your Cozy Corner Tonight” and “Your Next Favorite Coffee Spot Awaits.”

--------------------------------------------------

4. Tone Adaptation Prompt

Rewrite the website copy for a modern cafe using a warm, friendly, confident, and premium tone. The language should remain simple, emotionally engaging, stylish, and easy to understand. Ensure the writing feels human-written and realistic while avoiding robotic AI phrasing or unnatural wording.

--------------------------------------------------

5. Premium UI/UX Direction Prompt

Suggest premium UI/UX ideas for a modern cafe website. Include premium color palettes, typography pairings, hero section layouts, glassmorphism cards, hover animations, smooth scrolling effects, cinematic gallery ideas, mobile-first responsiveness, 3D card interactions, glowing buttons, animated navbars, parallax scrolling, and cursor interactions. The website should feel luxurious, immersive, highly interactive, modern, and visually premium. The UI should improve customer engagement and create a high-end brand experience.
