PREMIUM CAFE WEBSITE PROMPT FRAMEWORK

--------------------------------------------------
1. HOMEPAGE COPY PROMPT
--------------------------------------------------

Create premium homepage copy for a modern local cafe website.

Generate:
- a strong emotional headline
- a modern subheadline
- a short introduction section
- a value proposition
- premium CTA buttons

The website should feel:
- cozy
- modern
- luxurious
- welcoming
- visually aesthetic

Use human-sounding and emotionally engaging language.

Avoid:
- robotic AI phrasing
- generic business copy
- repetitive wording

The content must feel realistic and ready for a real website launch.

Tone:
- warm
- stylish
- friendly
- premium

--------------------------------------------------
2. SERVICES PAGE PROMPT
--------------------------------------------------

Create premium service page content for a modern cafe website.

Generate content for:
- artisan coffee
- desserts
- breakfast meals
- workspace seating
- free WiFi
- live music or events

For each service include:
- service title
- short premium description
- emotional customer benefit
- why customers should choose this service

The language should feel:
- business-specific
- premium
- natural
- customer-focused

Avoid generic AI wording.
The final content must feel publish-ready.
